# AGENTS.md

C++23 MOBA simulator. CMake + Ninja, Catch2 v3 tests, SDL3 view layer, Nix flake for the
toolchain. See `README.md` for the domain-level tour.

## Environment

All tooling comes from the Nix dev shell (`.envrc` = `use flake`). Outside `nix develop` /
direnv, `cmake` cannot find SDL3 or Catch2 and configure fails. Nix flake `systems` are
`x86_64-linux` and `aarch64-linux` only — no Darwin.

`build/` is already configured (Ninja, `RelWithDebInfo`). Reuse it.

## Commands

```sh
cmake --build build                  # incremental build
ctest --test-dir build               # all 38 tests
ctest --test-dir build -R "Vec2"     # filter by ctest test name (regex)
./build/tests/moba_sim_tests "[stats]"   # filter by Catch2 tag — ctest cannot
nix build                            # full clean build; doCheck=true runs ctest
nix flake check --print-build-logs    # what CI runs: nix build + pre-commit hooks
pre-commit run --all-files           # clang-format + nixfmt
```

`catch_discover_tests` registers each `TEST_CASE` as its own ctest test named by the test
case string. No ctest labels exist, so Catch2 tags (`[stats]`, `[champion]`, `[item]`,
`[events]`) are only usable by invoking the test binary directly.

`nix fmt` formats **Nix files only** (`nixfmt-tree`). C++ formatting happens through the
clang-format pre-commit hook, never `nix fmt`.

`-Werror` is **off** by default and CI never enables it, so warnings pass CI silently. The
warning set is aggressive (`-Wall -Wextra -Wpedantic -Wconversion -Wshadow`); before
finishing work, verify with a throwaway build dir:

```sh
cmake -B /tmp/wbuild -G Ninja -DMOBA_SIM_WARNINGS_AS_ERRORS=ON && cmake --build /tmp/wbuild
```

`-Wconversion` is why the codebase is full of explicit `static_cast<float>` around
`double` simulation values (see `src/view/demo.cpp`).

## Structure

Two libraries, both with `src/` on the include path:

- `moba_sim_core` — `stats/`, `champions/`, `items/`, `events/`. No SDL dependency.
- `moba_sim_view` — `view/`. Links `SDL3::SDL3`.

Executables: `moba-sim` (`src/main.cpp`, console event demo), `moba-sim-view`
(`src/view/demo.cpp`, SDL demo). Tests link both libraries.

Sources are listed explicitly in `src/CMakeLists.txt` and `tests/CMakeLists.txt` — no
globbing. A new `.cpp` must be added there or it is silently not compiled.

Includes are always rooted at `src/`: `#include "stats/stat_pipeline.hpp"`. Never relative.

## Nix layout

`flake.nix` only wires `flake-parts` + `import-tree ./nix`. All real configuration lives in
`nix/default.nix`; any `.nix` file dropped under `nix/` is auto-imported as a flake-parts
module.

`.pre-commit-config.yaml` is a **symlink into `/nix/store`** generated by `git-hooks.nix`.
Do not edit it. Change hooks via `pre-commit.settings.hooks` in `nix/default.nix`.

## Stat pipeline invariants

`result = sum(Base) * (1 + sum(Inc)) * product(1 + More)`.

Adding a `StatId` requires four coordinated edits, or you get silent corruption:

1. the `StatId` enum (`src/stats/stat_id.hpp`)
2. `kAllStats` in the same file — `kStatCount = kAllStats.size()` sizes
   `Champion::pipelines_`, and `stat_index()` is a raw `static_cast` of the enum, so a
   missing entry means out-of-bounds array access, not a compile error
3. the `spec_for()` switch in `src/champions/champion.cpp` — it has no `default` and ends in
   `std::unreachable()`, so a missing case is only a `-Wswitch` warning then UB at runtime
4. a matching `<stat>` / `<stat>_growth` field pair on `ChampionData`

`Champion::unequip` calls `seed_pipelines()` and replays the remaining items, so any
modifier pushed directly through `Champion::pipeline(stat)` is **discarded** on unequip.

## Events

`Event` is a `std::variant` including `std::shared_ptr<EventSequence>` for recursive nesting,
with `EventSequence` forward-declared before the alias. Dispatch is `std::visit` over free
`handle_event` overloads resolved at the call site in `src/events/event.cpp`.

Adding an event type: new `hpp`/`cpp` pair under `src/events/` declaring a `handle_event`
overload, add the type to the `Event` variant in `event.hpp`, include the header from
`event.cpp`, and register the `.cpp` in `src/CMakeLists.txt`.

`process_event`'s `debug_out` defaults to a badbit stream, so event handling is silent unless
a stream is passed.

## Tests

Tests must be headless. `tests/game_loop.test.cpp` calls
`setenv("SDL_VIDEO_DRIVER", "dummy", 1)` itself; any new SDL-touching test has to do the
same, since the environment is not set globally by ctest or the Nix build.

Champion tests use real League of Legends wiki numbers (Ahri) with expected values worked out
in comments — keep that pattern when extending them.

## Conventions

- clang-format: LLVM base, 4-space indent, 100-column limit, `Type* ptr` pointer alignment.
- Namespaces: `moba_sim`, `moba_sim::view`.
- Headers use `#pragma once`, not include guards.
- Public API carries `///` doc comments and `[[nodiscard]]` on pure accessors.
- Commits: imperative capitalized subject, no prefix or scope
  (`Store Champion pipelines in a StatId-indexed array`), with an optional wrapped body
  explaining the rationale for non-trivial changes.
- CI runs on pushes to `main` and on pull requests.
